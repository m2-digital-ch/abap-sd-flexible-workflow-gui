# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-09-07

### Added
- Status button in the VA03 toolbar showing the approval status of the flexible workflow
- Header tab "Approval" with a SALV tree of workflow runs and steps
- Note popup for decision comments (double-click on a step)
- Scope class ZCL_SD_APM_WF_SCOPE to configure transaction and document categories
- Report ZSD_APM_WF_DISPLAY showing the workflow of one document as ALV list (verification, support)
- Application log (object ZSD_APM, subobject WF_DISPLAY) for technical errors of the reader
- Message class ZSD_APM with all UI texts
